# #78 Frames missing from the cache

Set out to: find why the detection head refused the finished cache.
Found: the cache picked frames from the list of RGB-thermal pairs, but the per-camera splits also hold labelled frames with no partner in the other camera: 5 RGB and 3 thermal. The head refuses an incomplete cache, so every fold was refused.
Decision: the cache selects paired frames first, then any frame a fold manifest references; `check-cache` lists what is missing and exits non-zero.
Worth telling: the refusal was the system working. Leaving the 8 frames out silently would have changed the test sets by a hair and nobody would have known.
Sources: PR #79; issue #78's handoff.
