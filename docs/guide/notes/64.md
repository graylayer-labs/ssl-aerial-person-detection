# #64 Cost of one forward pass

Set out to: measure time and feature size per image on the laptop.
Found: SigLIP 2 at about 512 px is 92 ms (mains) to 126 ms (battery) per image; pooled cache 11.5 GB, about an hour. 1024 px is 4 to 6 hours and 45 GB pooled. A locked screen throttles the GPU and ruins the numbers.
Decision: first cache is SigLIP 2 NaFlex at a 1,024-token budget, pooled 2×2, built one camera per session.
Sources: docs/forward-pass-cost.md.
